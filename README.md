# Pérdidas insensibles en adultos

Calculadora web sencilla para estimar las pérdidas insensibles de agua en un
adulto.

## Uso

Abre `index.html` en un navegador, ingresa el peso en kilogramos y el tiempo en
horas, y selecciona **Calcular pérdida estimada**.

La estimación usa la fórmula:

```text
PI (mL) = 0.5 mL/kg/h × peso (kg) × tiempo (h)
```

El resultado se expresa en mililitros. Es una estimación y no sustituye la
valoración clínica.
